\# Báo cáo Bài 4: Quản lý tệp tin bỏ qua (.gitignore) và Sửa lịch sử



\## 1. Cách gỡ bỏ file khỏi cache

Để gỡ file `credentials.txt` khỏi sự theo dõi của Git mà vẫn giữ lại tệp vật lý trên máy, em đã sử dụng lệnh:

`git rm --cached homework/session\_04/ex4/credentials.txt`
